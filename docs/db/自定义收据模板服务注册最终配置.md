## ⚠️ 重要提示

### 1. Redis缓存

**必须重启后端服务**才能使新的路由配置生效：

```bash
# 停止服务
kill -9 $(ps aux | grep service-api | grep -v grep | awk '{print $2}')

# 启动服务
cd /path/to/springboot/target
nohup java -jar service-api.jar > logs/service-api.log 2>&1 &

# 查看日志
tail -f logs/service-api.log
```

### 2. 验证步骤

重启后，请按以下步骤验证：

#### 步骤1：检查Redis缓存

```bash
redis-cli
GET "8000418004_SUFFIX_APP_ROUTE"
# 应该返回包含以下service_id的JSON：
# - 982021091677750027 (list)
# - 982026061566580007 (save)
# - 982026061579900008 (update)
# - 982026061542850009 (delete)
```

#### 步骤2：测试前端功能

1. 访问模板设计器：`http://your-domain/#/views/system/templateColumnDesigner`
2. 配置并保存模板
3. 应该显示"保存成功"

#### 步骤3：检查浏览器Network

按F12打开开发者工具，查看Network标签：
- 找到`feePrintPageTemplate.saveFeePrintPageTemplate`请求
- 状态码应该是200
- Response应该是：`{"code":0,"msg":"success"}`
