# 自定义收据模板 - 数据库升级执行脚本

## 📋 概述

本文档说明如何将自定义收据模板功能所需的数据库变更应用到正式数据库（TT.sql）。

**升级内容**：
1. 通过 WEB 管理界面创建 3 条服务信息（c_service）
2. 通过 WEB 管理界面创建 3 条路由权限（c_route）
3. 修改 `fee_print_page_template` 表的 `url` 字段类型（varchar → MEDIUMTEXT）

**适用版本**：MicroCommunity  
**执行时间**：约 10 分钟（WEB 操作 + 1 条 SQL）  
**操作方式**：WEB 管理界面（DEV 账号）+ 1 条 ALTER TABLE

---

## ⚠️ 重要提示

### 执行前准备

1. **备份数据库**（必须！）
   ```bash
   mysqldump -u root -p tt > backup_$(date +%Y%m%d_%H%M%S).sql
   ```

2. **确认 DEV 账号可用**
   - DEV 超级管理员账号需具备「系统管理 → 服务配置」和「系统管理 → 路由配置」的读写权限

3. **确认当前状态**
   ```sql
   -- 检查 fee_print_page_template 表 url 字段当前类型
   DESCRIBE fee_print_page_template;
   
   -- 检查是否已存在同名服务
   SELECT * FROM c_service WHERE service_code LIKE 'feePrintPageTemplate.%';
   ```

> 💡 通过 WEB 界面操作会自动生成 `id` 和 `service_id`，不会出现 ID 冲突问题。

## 📝 升级步骤

> **重要变更**：本升级不再直接执行 SQL 脚本，改用前端 WEB 管理界面的 **DEV 超级管理员账号** 操作，避免 ID 冲突和手动 SQL 风险。

### 步骤1：登录 WEB 管理界面

### 步骤4：修改 url 字段类型

由于 WEB 界面不支持直接修改表结构，仍需在数据库中执行一条语句：

```sql
ALTER TABLE fee_print_page_template 
MODIFY COLUMN url MEDIUMTEXT NOT NULL COMMENT '收据页面URL或Base64编码后的HTML内容';
```

> 此操作仅修改字段类型（varchar→MEDIUMTEXT），不涉及数据变更，可在线执行无需停机。

**变更说明**：
- `url` 字段类型从 `varchar(512)` 改为 `MEDIUMTEXT`
- MEDIUMTEXT 最大支持 16MB，足够存储 Base64 编码后的 HTML 模板

## 🔍 故障排查

### 问题1：WEB 界面找不到「服务配置」菜单

**原因**：DEV 账号权限不足或菜单未配置。

**解决方法**：检查 DEV 账号的角色权限，确保包含「系统管理」模块的读写权限。

### 问题2：保存服务时提示 service_code 已存在

**原因**：该服务编码已注册，可能是之前的升级残留。

**解决方法**：在服务配置页面搜索该 service_code，确认是否已存在且状态正常。如果已存在则无需重复创建。

### 问题3：仍然报"鉴权失败"

**原因**：Redis 缓存未刷新。

**解决方法**：
```bash
# 1. 重启后端服务（WEB 操作的服务/路由信息会自动刷入缓存）
# 2. 或手动清除 Redis 缓存
redis-cli
DEL service_config_cache
# 3. 重新测试
```
