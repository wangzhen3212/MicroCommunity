# HC小区物业管理系统项目说明

## 项目概述

**HC小区管理系统**是一套成熟的SaaS物业管理系统，已在多个地方商用超过四年半时间。系统采用微服务架构，支持Spring Cloud和Spring Boot两种部署方式。

## 系统架构

### 技术栈
- **后端框架**: Spring Boot 2.0.4.RELEASE + Spring Cloud Finchley.SR3
- **数据持久层**: MyBatis 3.5.6 + MySQL 8.0.16
- **缓存**: Redis + Ehcache
- **消息队列**: ActiveMQ
- **服务注册发现**: Eureka
- **API文档**: Swagger 2.5.0
- **构建工具**: Maven
- **Java版本**: 1.8

### 系统组成
1. **物业系统后端** (当前项目) - 核心业务处理
2. **物业系统前端** - 物业员工电脑端
3. **业主手机端** - 业主使用的移动应用
4. **物业手机版** - 物业员工移动端

## 功能模块

### 核心业务模块
- **service-user**: 用户服务
- **service-community**: 社区服务
- **service-store**: 商户服务
- **service-fee**: 费用服务（支持在线支付）
- **service-order**: 订单服务
- **service-acct**: 账户服务
- **service-report**: 报表服务
- **service-oa**: 办公自动化
- **service-job**: 任务调度
- **service-dev**: 开发服务
- **service-scm**: 供应链管理

### 基础模块
- **java110-core**: 核心业务逻辑
- **java110-service**: 服务层
- **java110-bean**: 数据模型
- **java110-utils**: 工具类
- **java110-interface**: 接口定义
- **java110-db**: 数据库相关

## 主要功能

### 物业管理
- 房产信息管理
- 业主信息管理
- 费用管理（支持线上缴费）
- 报修管理（支持线上报修）
- 投诉建议管理

### 运营管理
- 采购管理
- 巡检管理
- 停车管理
- 门禁管理
- 道闸管理
- 监控管理

### 系统功能
- 工作流引擎
- 问卷调查
- 公告管理
- 报表统计

## 部署方式

### 支持两种部署模式
1. **Spring Cloud模式**: 完整的微服务架构
2. **Spring Boot模式**: 简化部署的单体应用模式

### 环境要求
- Java 1.8+
- MySQL 8.0+
- Redis
- ActiveMQ (可选)
