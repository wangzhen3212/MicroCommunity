# HC小区管理系统 - 新手上手指南

## 项目概述

HC小区管理系统是一套成熟的SaaS物业管理解决方案，已经商用超过四年半时间。系统采用微服务架构，提供完整的物业管理功能，包括房产管理、业主管理、费用管理、报修管理、投诉建议等核心业务模块。

### 核心功能

- **房产管理**：小区、楼栋、房屋信息管理
- **业主管理**：业主信息、家庭成员管理
- **费用管理**：物业费、停车费等费用管理，支持线上缴费
- **报修管理**：线上报修申请、维修进度跟踪
- **投诉建议**：业主投诉建议收集与处理
- **停车管理**：车位管理、停车费管理
- **安防管理**：门禁、道闸、监控系统集成
- **工作流**：业务流程自定义配置
- **问卷公告**：社区问卷、公告发布

## 快速入门指南

### 环境要求

- **操作系统**：Windows/Linux/macOS
- **Java环境**：JDK 8+
- **数据库**：MySQL 5.7+
- **内存**：最低4GB，推荐8GB
- **网络**：可访问互联网（用于下载依赖）

### 安装部署步骤

#### 方式一：Spring Boot方式启动（推荐新手）

1. **环境准备**
   ```bash
   # 确保已安装JDK 8+
   java -version
   
   # 确保已安装Maven
   mvn -version
   ```

2. **数据库配置**
   - 创建MySQL数据库
   - 导入数据库脚本（位于java110-db目录）
   - 修改数据库连接配置

3. **启动服务**
   ```bash
   # 进入springboot目录
   cd springboot
   
   # 启动服务
   mvn spring-boot:run
   ```

4. **访问系统**
   - 打开浏览器访问：http://localhost:3000
   - 使用演示账号登录

#### 方式二：Spring Cloud方式启动

1. **启动注册中心**
   ```bash
   cd java110-eureka
   mvn spring-boot:run
   ```

2. **启动各业务服务**
   ```bash
   # 依次启动各个服务模块
   cd java110-service/service-user
   mvn spring-boot:run
   
   cd ../service-community
   mvn spring-boot:run
   
   # 其他服务模块...
   ```

### 快速切换部署方式

系统提供了便捷的部署方式切换脚本：

- **Windows系统**：
  ```cmd
  # 切换到Spring Boot方式
  changeBootEnvWindow.bat
  
  # 切换到Spring Cloud方式  
  changeCloudEnvWindow.bat
  ```

- **Linux系统**：
  ```bash
  # 切换到Spring Boot方式
  ./changeBootEnvLinux.sh
  
  # 切换到Spring Cloud方式
  ./changeCloudEnvLinux.sh
  ```

## 常见问题解答

### Q1: 启动时遇到端口被占用怎么办？
A: 修改application.yml中的server.port配置，或停止占用端口的进程。

### Q2: 数据库连接失败怎么办？
A: 检查数据库服务是否启动，数据库连接配置是否正确。

### Q3: 如何修改开发者账号密码？
A: 参考[密码修改指南](http://bbs.homecommunity.cn/pages/bbs/topic.html?topicId=102021110520080050)

### Q4: 前端页面无法访问？
A: 确保前端服务已启动，检查端口配置，确认防火墙设置。

### Q5: 微服务注册失败？
A: 检查Eureka注册中心是否正常启动，网络连接是否正常。
